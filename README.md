# 🚗 Parking Spot Finder

A web application built with **React**, **Leaflet.js**, and **OpenStreetMap** that helps users search for locations and view nearby parking spots with real-time availability.

---

## 🌐 Features

- Interactive map with real-time parking spot availability  
- Search locations using OpenStreetMap API  
- Custom icons for available/unavailable parking  
- Toggle parking availability status  
- Clean and user-friendly UI

---

## 🛠️ Tech Stack

- React  
- react-leaflet  
- Leaflet.js  
- Axios  
- OpenStreetMap
